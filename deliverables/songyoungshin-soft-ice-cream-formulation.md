### 3-5. 계절 보정식 (저지 원유는 유지방 변동 폭이 큼)

원유 68.0 kg 고정, 원유 유지방 실측값 F(%), 무지유고형분 실측값 S(%)일 때:

```
유크림(38%) 투입량 C = (8.0 − 0.68 × F) ÷ 0.38   [kg]
탈지분유 투입량 SMP  = (11.0 − 0.68 × S − 0.056 × C) ÷ 0.97   [kg]
정제수 = 100 − (68.0 + C + SMP + 17.0 + 0.35)
```

| 원유 유지방 F | 유크림 투입량 |
|---|---:|
| 5.2 % | 11.75 kg |
| 5.5 % | 11.21 kg |
| 5.8 % (기준) | 10.70 kg |
| 6.1 % | 10.14 kg |

> **매 배치 원유 성분 검사(유지방·유단백·SNF) 후 위 식으로 보정**하는 것을 SOP에 고정하십시오. 이 한 가지만 지켜도 맛의 배치 편차가 대부분 사라집니다.

### 3-6. 단위 주의 (중요)

기존 컨텍스트의 A2 저지 헤이밀크 성분표는 **100 mL 기준**(유지방 6.0 g, 단백질 4.59 g)입니다. 배합 계산은 **중량(w/w) 기준**이어야 하므로 비중 1.032를 적용해 유지방 **약 5.8 %(w/w)**, 무지유고형분 **약 10.1 %(w/w)** 로 환산해 사용했습니다. 실제 배합 전 목장 원유의 w/w 성분 분석값으로 재확인 필요.
