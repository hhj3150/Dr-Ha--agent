## 2. 가격 설계 로직 — 이 순서로 숫자를 확정하십시오

### STEP 1. 제조원가(COGS) 산출 — 1병 기준

| 원가 항목 | 750 mL 기준 | 산출 근거 |
|---|---|---|
| 원유비 | 【 】원 | 사용 원유량 × 자가 원유 환산단가 |
| 포장재 (용기+캡+라벨) | 【 】원 | 공급사 단가 |
| 가공비 (인건·에너지·감가) | 【 】원 | 월 가공비 ÷ 월 생산병수 |
| 검사·품질관리비 | 【 】원 | 자가품질검사 분담 |
| **제조원가 소계** | **【 】원** | |
| 물류비 (냉장 배송) | 【 】원 | 회차당 배송비 ÷ 회차당 납품수량 |
| 폐기·반품 손실 | 【 】원 | 소비기한 짧은 신선품 — **판매액의 3~5% 반영 권장** |
| **총원가** | **【 】원** | |

> **신선 유제품의 최대 리스크는 폐기입니다.** 소비기한이 짧을수록 미판매 폐기가
> 마진을 잠식합니다. 반드시 원가에 미리 반영하십시오.

### STEP 2. 소비자가(판매가) 결정 — 포지셔닝 기준

프리미엄 식품관에서는 **원가 가산이 아니라 포지셔닝으로 소비자가를 먼저 정하고,
역산으로 공급가를 맞추는** 방식이 정석입니다.

| 포지션 | 750 mL 소비자가 대역 | 메시지 |
|---|---|---|
| 고급 우유 | 6,000~8,000원 | "좋은 우유" |
| **프리미엄 목장형** | **9,000~13,000원** | **"A2A2 + 저지 + 헤이밀크" ← 권장 대역** |
| 초프리미엄/한정 | 14,000원 이상 | 한정·기획 상품 |

권장: **A2A2 유전자 선발 + 저지 + 목장형 유가공 + 유지방 6.0%** 라는 4중 근거를
갖춘 제품이므로 **프리미엄 대역 상단**에 위치시키는 것이 브랜드 전략상 유리합니다.
초기에 낮게 진입하면 이후 인상이 사실상 불가능합니다.

### STEP 3. 거래 형태별 공급가 역산

백화점 식품관은 통상 두 가지 구조 중 하나입니다. **어느 구조인지 홍 이사께
먼저 확인**한 뒤 아래 식을 적용하십시오.

**① 특정매입 (수수료 방식)** — 판매분에 대해 수수료 차감 후 정산
```
정산액 = 소비자가 × (1 − 수수료율)
```
| 소비자가 | 수수료 25% | 수수료 30% | 수수료 33% |
|---|---|---|---|
| 9,900원 | 7,425원 | 6,930원 | 6,633원 |
| 12,000원 | 9,000원 | 8,400원 | 8,040원 |
| 13,500원 | 10,125원 | 9,450원 | 9,045원 |

**② 직매입 (공급률 방식)** — 백화점이 매입, 재고·폐기 리스크는 백화점 부담
```
공급가 = 소비자가 × 공급률
```
| 소비자가 | 공급률 65% | 공급률 70% | 공급률 75% |
|---|---|---|---|
| 9,900원 | 6,435원 | 6,930원 | 7,425원 |
| 12,000원 | 7,800원 | 8,400원 | 9,000원 |
| 13,500원 | 8,775원 | 9,450원 | 10,125원 |

*수수료율·공급률 범위는 업계 통상 대역이며, 실제 조건은 갤러리아와의 협의로 확정됩니다.*

### STEP 4. 마진 검증 (반드시 통과할 것)

```
공헌이익 = 정산액(또는 공급가) − 총원가(STEP 1)
공헌이익률 = 공헌이익 ÷ 정산액
```

**판정 기준**
- 공헌이익률 **35% 이상** → 진행 가능
- 25~35% → 조건부. 물량으로 커버되는지 손익분기 확인
- **25% 미만 → 소비자가를 올리거나 입점 조건을 재협상.** 물량이 늘어도 적자는 커집니다.

### STEP 5. 채널 간 가격 정합성 (중요)

**자사몰 shop.a2jerseymilk.com 가격보다 백화점 가격이 낮으면 안 됩니다.**
백화점은 최저가 조항을 요구하는 경우가 있고, 반대로 자사몰이 더 싸면
백화점 매장이 쇼룸으로만 소비됩니다.

| 채널 | 권장 가격 정책 |
|---|---|
| 갤러리아 매장 | **기준가 (최저)** |
| 자사몰 단품 | 기준가 동일 |
| 자사몰 정기구독 | 기준가 대비 할인 — **"구독 혜택"으로 정당화** (일반 판매가는 동일 유지) |
| 기타 온라인 | 기준가 이상 |

→ 정기구독 할인은 **가격 인하가 아니라 멤버십 혜택**으로 설계해야 백화점과 충돌하지 않습니다.

## 3. 바코드(GTIN-13) 확보 — 미보유 시 즉시 착수

백화점 POS 등록에는 **GS1 표준 바코드가 필수**입니다. 자체 임의번호는 등록 불가입니다.

| 상황 | 조치 | 소요 |
|---|---|---|
| GS1 Korea 회원 **보유** | 상품별 GTIN-13 채번 → 라벨 반영 | 즉시 |
| GS1 Korea 회원 **미보유** | GS1 Korea 회원가입 → 업체코드 부여 → 채번 | **약 1~2주** |

**채번 규칙**: `880` (국가코드) + 업체코드 + 상품코드 + 체크디지트
**주의**: 용량이 다르면 **각각 다른 바코드**가 필요합니다. (750mL과 500mL은 별도 GTIN)

## 4. 소비기한 표기 — 확인 필수

- 「식품등의 표시·기준」상 **유통기한 → 소비기한** 표기로 전환되어 있습니다.
  현재 라벨이 "유통기한"으로 되어 있다면 **라벨 개정 + 품목제조보고 변경**이 선행되어야 합니다.
- 저온살균(75℃/20초) 우유는 초고온 살균 대비 **소비기한이 짧습니다.**
  실제 설정값과 설정사유서(2번 문서 2-7) 기준을 그대로 기재하십시오.
- 백화점 납품 시 **잔여 소비기한 기준(예: 소비기한의 2/3 이상 잔여)** 을 요구하는
  경우가 있습니다. 소비기한이 짧을수록 배송 빈도를 높여야 하므로,
  **주 2회 이상 배송 체계**를 6.2항(3번 문서)에서 함께 제안하십시오.
