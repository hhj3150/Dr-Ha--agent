## 0. 한 장 요약 (회장님 결론부터)

- **인프로가 먼저 깃발을 꽂았다.** 우즈베키스탄 최대 국영 농업금융은행(Agrobank)과 MOU + 약 30.6만 달러 시범사업 계약을 동시 체결(2026-06-17, 타슈켄트). 본사업 약 1,000만 달러 확대를 목표로 명시.
- **그러나 인프로 모델은 "센서 + 영상분석 + 데이터 플랫폼" 수준**으로 보도됨. 우리가 구상하는 **위내센서(반추위) 기반 예측 AI + 공공데이터·금융/보험 연계 국가 축산 OS**보다 기술 심도와 확장 축이 좁다.
- **우리의 진짜 차별점은 세 가지**: ① 반추위 볼러스 센서의 생리 예측력(발정·분만·질병), ② 한국 홀스타인 성감별 수정란 수출과의 결합(유전개량 + 데이터), ③ 정부/금융 연계형 국가 데이터 허브 구조.
- **핵심 위험**: 우즈벡 축산 디지털 시장에서 "선점 레퍼런스 = 표준"이 될 수 있음. 인프로가 Agrobank라는 **금융 인프라(대출·보험 심사 데이터 수요자)**를 파트너로 확보한 것이 특히 위협적.
- **권고**: 인프로와 정면 충돌(같은 센서/영상 사업 재입찰)하지 말고, **상위 레이어(예측 AI + 유전개량 + 금융 리스크 데이터)로 포지셔닝**하여 ① 보완·상호보완 제휴 또는 ② 차별화 독자 파일럿(우리 50두 실증 레퍼런스 활용) 중 하나를 3개월 내 결정.

## 3. SWOT — 우즈벡 전선에서의 우리 위치

**Strengths**
- 반추위 볼러스 예측 AI(발정·분만·질병) + smaXtec 국내 독점 공급·API
- 홀스타인 성감별 수정란(유전개량) + 우즈벡 RDA 협력 이력 + ~50두 CowTalk 실증
- 경기 102.3억 국가급 플래그십(진행 시 강력한 대외 신뢰자산)

**Weaknesses**
- 우즈벡 정부계약 미체결(속도 열위), 현지화 SW·현지 조직 부재
- 금융 앵커(Agrobank급) 미확보
- 예측 모델의 대규모 필드 검증 데이터 부족

**Opportunities**
- 인프로 실증이 만든 **시장 각성**을 무임승차(수요·예산 형성)
- 금융/보험 연계(가축대출 리스크 심사) = 인프로 SI를 얹을 상위 데이터 레이어
- 수정란 수출 + 데이터 후속관리 결합 = 인프로가 못 하는 패키지

**Threats**
- **선점=표준화** 리스크: Agrobank 데이터 규격이 국가 표준이 되면 후발 진입 장벽
- 인프로가 본사업(1,000만 달러) 단독 수주 시 우즈벡 축산 디지털 폐쇄
- 우즈벡 결제/규제/데이터 주권 리스크(공통)

## 4. 전략 옵션 3안 (권고 포함)

### 옵션 A — 상위 레이어 보완제휴 (⭐ 1순위 권고)
인프로의 센서/영상/플랫폼 위에 **우리 예측 AI + 유전개량 + 금융리스크 데이터**를 얹는다.
- 대(對)Agrobank 가치: 대출·가축보험 심사용 **개체 생리·번식·질병 리스크 스코어** 제공(인프로 영상만으론 불가).
- 우리 이익: 정면 자본경쟁 회피, 인프로 실증 인프라 재활용, 수정란 수출과 결합.
- 리스크: 인프로가 데이터/IP 종속을 노릴 수 있음 → 데이터 소유·API 경계 계약 필수.

### 옵션 B — 차별화 독자 파일럿 (2순위, 병행 가능)
우즈벡 내 **다른 앵커**(농업부·수의당국·낙농협·타 은행/보험)와 **반추위 예측 + 수정란 개량** 통합 실증을 독자 추진. ~50두 실증을 확대 레퍼런스로 사용.
- 강점: 포지셔닝 완전 차별화(예측·유전), 우리 8대 수익모델 그대로 이식.
- 리스크: 인프로와 예산·정책 경합, 현지 조직·현지화 투자 필요.

### 옵션 C — 관망·국내 플래그십 우선 (3순위)
경기 102.3억 플래그십을 먼저 굳혀 국가급 레퍼런스를 확보한 뒤 우즈벡 재진입.
- 강점: 자원 집중, 실증 데이터 축적.
- 리스크: 인프로 본사업 선점으로 우즈벡 창(window) 상실 가능.

> **하실장 권고:** **A를 주축 + B를 백업**으로 동시 가동. 즉, 인프로/Agrobank에는 "예측·금융리스크·유전개량" 상위 제휴를 타진하면서, 병행하여 우즈벡 내 제2앵커로 독자 파일럿 옵션을 열어 협상 레버리지를 확보. C(국내 우선)는 자원이 부족할 때의 후퇴선.

## 7. 확인이 필요한 회장님 결정사항

- **자원 배분**: 우즈벡 능동 진입에 인력·자금을 지금 투입할지, 경기 플래그십 우선인지.
- **금융 앵커 전략**: 우리도 은행/보험(국내 농협·축협·보험사, 또는 우즈벡 현지)과 금융-데이터 제휴를 정식 사업축으로 세울지.

## 8. 긴급 결정 메모 — 인프로 최승혁 대표의 "CowTalk 센서 50개 공급" 문의 (2026-07-09)

### 상황
인프로 최승혁 대표가 **Agrobank 우즈벡 플랫폼에 쓸 CowTalk(smaXtec 볼러스) 센서 50개 공급 가능 여부**를 문의. 규모(50두)가 우리 우즈벡 실증(~50두)과 동일 — **파일럿 스케일 주문, 매출은 작지만 전략적 의미는 큼.**

### 하실장 해석 (신호 읽기)
1. **경쟁자가 먼저 왔다 = 우리 기술 우위의 자백.** 영상분석·목걸이·귀태그로는 반추위 생리신호(발정·분만·질병 예측)를 못 낸다. 인프로가 우리 볼러스를 원한다는 건 §2-A 우위가 실증된 것.
2. **우리가 두려워하던 "폐쇄" 리스크가 "진입" 기회로 반전.** 인프로 실증 인프라 안에 우리 센서·데이터가 들어가면, 우즈벡 전선에서 배제되기는커녕 **핵심 부품 공급자**로 안착.
3. **단, 그냥 팔면 우리는 하드웨어 납품업체로 전락**한다. 플랫폼·데이터·고객관계는 인프로가 갖고, 우리는 1회성 센서값만 받는 구조 → 1,000만 달러 본사업의 과실은 인프로가 독식.

### 권고: **조건부 YES — 단, "맨하드웨어 단독 판매"는 금지**
이 인바운드를 §4 옵션 A(상위 레이어 제휴)로 전환한다. 센서 50개는 **반드시 CowTalk 데이터 파이프라인/API + 관리·구독 계약과 묶어서만** 공급.

**공급 시 반드시 관철할 4대 조건**
1. **데이터 경로·소유권**: 볼러스 데이터는 우리 CowTalk/smaXtec API를 경유. 데이터 소유·2차활용 경계를 계약 명문화. (우리가 API를 쥐면 하드웨어 벤더가 아니라 데이터 레이어 사업자가 된다.)
2. **번들 구조**: 센서 + 데이터연동 + AI리포트 + 관리비/구독을 패키지로. 1회성 50개 매출이 아니라 **경상수익 + 본사업 교두보**로 설계.
3. **비독점**: 인프로 전용 종속 금지. 우즈벡 내 제2앵커(농업부·수의당국·보험) 병행 진입 여지 확보(옵션 B 레버리지 유지).
4. **기밀·IP 보호**: 대외 판매가만 노출(설치·구독·4년 무상교체·국내 독점공급/API 보유 사실). **내부 원가·마진·지분·수입단가는 절대 비공개**(기밀규칙 §5).

### 반드시 먼저 확인할 게이팅 이슈 (YES 전 필수)
- ⚠️ **smaXtec 해외 공급권**: 우리 smaXtec 독점은 **국내(國內) 독점**. 우즈벡(해외)으로 볼러스를 공급·수출할 **권리·수출승인·해외 워런티(4년 무상교체 적용 여부)**를 제조사(smaXtec)와 먼저 확인. 이게 안 되면 공급 자체가 불가.
- **수출 물류·통관·현지 데이터주권**: 센서 반출입, 현지 데이터 저장 규제.
- **가격 재설계**: 국내가 그대로 적용 금지 — 해외는 국내 독점 프리미엄이 없고 물류·환리스크가 있으므로 **수출용 별도 가격·계약 구조** 필요.

## 8-bis. 최종 결정 (회장님 판단, 2026-07-09) — **공급하지 않음 · 제휴하지 않음**

### 결정
인프로에 CowTalk 센서를 **공급하지 않는다.** 조건부 공급(데이터 레이어 번들)도 하지 않는다. 우즈벡 시장을 일부 포기하더라도 인프로와는 함께 가지 않는다.

### 판단 근거 (회장님 + 하실장 정리)
1. **상대 실체 부실**: 국내에서 실체·트랙레코드가 약한 회사가 이 규모 프로젝트를 수주 → 능력이 아닌 영업 기반 수주로 판단. 프로젝트 실패 가능성 높음. (일부 능력은 인정.)
2. **"센서를 사러 온 것" 자체가 기술 기반 부재의 증거**: 자기 센서에 확신 있는 회사는 남의 센서를 사러 오지 않는다.
3. **연대책임·레퍼런스 오염**: 실패할 프로젝트에 우리 센서가 들어가면 "우리 센서 썼는데 실패"라는 독(毒) 레퍼런스가 남아 CowTalk 국제 확장의 신뢰 자산을 훼손. 우리 ~50두 실증 레퍼런스의 가치를 정반대로 뒤집음.
4. **포지셔닝·신뢰 일관성**: "과학적 신뢰 기반 국가급 축산 OS"라는 우리 정체성과, 실체 부실 벤더와의 제휴는 모순. 장차 우리 신뢰에 문제.

### 중요한 재정의 — "우즈벡 포기"가 아니다
버리는 것은 **인프로라는 통로**이지 우즈벡 시장이 아니다. 인프로 없이 독자 진입 가능한 자산 보유:
- RDA 협력 + 홀스타인 성감별 수정란 ~3년 수출 레퍼런스
- 우리 ~50두 CowTalk 독자 실증
- G2G(농업부·수의당국)·ODA/KOICA·현지 은행/보험 직접 채널

→ **인프로는 거절, 우즈벡은 우리 이름으로 훗날 정공법 재진입.**

### 실행
1. **정중하고 단호한 거절 회신**: 내부 사유(실체 부실 판단) 비노출. "당사 정책상 단순 센서 단독 공급은 하지 않으며, 데이터·AI 통합 사업 형태로만 진행한다"는 톤으로 다리를 거칠게 태우지 않되 명확히 거절.
2. **우즈벡 독자 재진입 트랙 유지**: 옵션 B를 우리 주도·우리 파트너로 별도 설계(인프로와 무관).
3. **레퍼런스 보호**: 우리 ~50두 실증을 인프로 건과 명확히 분리해 대외 커뮤니케이션.

### 상태
- 옵션 A(상위 레이어 제휴) — **폐기.**
- 옵션 B(차별화 독자 진입) — **채택·재정의**: 인프로가 아니라 **농진원 정부 프로젝트 트랙**으로 진행(아래 §8-ter).
- 옵션 C(국내 플래그십 우선) — **국내 주력 병행.** 경기 102.3억 플래그십에 자원 집중.

## 8-ter. 우즈벡 진입 채널 확정 — **농진원(정부) 프로젝트 트랙** (회장님 안)

### 결정
우즈벡은 인프로를 경유하지 않고, **회장님이 이미 진행 중인 KOPIA(코피아) 정부 사업을 통해** 추진한다.
> ※ 채널 확정: **KOPIA = 농촌진흥청(RDA) 해외농업기술개발사업.** 인프로의 KOICA(외교부 무상원조)와 별개 재원·기관. 앞서의 "농진원" 언급은 이 KOPIA/RDA 채널로 이해.

### 이 트랙이 인프로 대비 우월한 근거
1. **정부기관 backing** — 인프로에서 지적된 "실체·신뢰 부재"를 구조적으로 해소.
2. **리스크 완화** — 결제·규제·데이터주권 리스크를 G2G/ODA/KOICA 프레임으로 흡수.
3. **속도·관계** — 이미 진행 중인 프로젝트라 현지 관계·트랙 존재 → 인프로 선점 열위 상쇄.
4. **사업 주도권** — 하청이 아니라 우리가 주도. 성감별 수정란 + ~50두 CowTalk 실증 + 번식데이터를 그대로 결합.

### ★ 결정적 사실 (회장님 확인, 2026-07-09)
**올해 진행 중인 우리 정부 사업 = KOPIA(코피아) 사업**에 이미 다음이 스코프로 포함되어 있음:
- 대상국: **우즈베키스탄 · 카자흐스탄 · 말레이시아** (중앙아 2 + 동남아 1)
- 사업축: **① 홀스타인 성감별 수정란 수출 + ② CowTalk 사업** (통합)

**★★ 인프로와 우리는 서로 다른 정부 사업 — 애초에 경쟁 구도가 아님:**
| 구분 | 인프로 | 우리(D2O/Genetics) |
|---|---|---|
| 재원·프로그램 | **KOICA(코이카)** — 외교부 산하 무상원조 | **KOPIA(코피아)** — 농촌진흥청(RDA) 해외농업기술개발사업 |
| 성격 | 디지털 ODA(센서·영상 SI) | **농업기술 이전**(유전개량 + 정밀축산) |
| 현지 인프라 | 단발 파일럿 | KOPIA 현지 센터·정부 네트워크 기반 |

→ 결론: ① 우즈벡은 "재진입"이 아니라 **KOPIA 사업이라는 정부 vehicle을 이미 보유**. ② **인프로(KOICA)와는 재원·기관·성격이 달라 직접 경쟁 아님** — 센서 공급 요청을 거절해도 우리 사업에 아무 지장 없음. ③ 우리 통합(수정란+CowTalk)은 **KOPIA의 농업기술이전 취지에 정확히 부합.** **회장님 정책: KOPIA 사업을 통해 구현한다.**
> ※ 용어정리: 앞서 언급된 "농진원"은 이 KOPIA(농촌진흥청/RDA 해외농업기술개발) 채널로 확정 이해. 주관기관 정식표기는 회장님 최종 확인.
