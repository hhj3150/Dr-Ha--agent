# [2번] 품목제조보고서 및 품질성적서 — 준비·제출 가이드

- 수신: 갤러리아백화점 홍석진 이사
- 발신: 송영신목장 / A2 저지 헤이밀크
- 작성: 하실장 (D2O Agent System) · 2026-08-07
- 【확인】 표시는 회장님·유가공 담당자 확인 후 확정할 항목입니다.

> **중요 — 이 문서의 성격**
> 품목제조보고서와 품질성적서는 **발급기관에서 나오는 원본 서류**이므로 여기서 대신
> 만들어 드릴 수 없습니다. 이 문서는 (1) 무엇을, (2) 어디서, (3) 어떤 상태로 뽑아
> 동봉해야 백화점 QA 심사를 한 번에 통과하는지에 대한 **실행 가이드 + 제출 커버시트
> 양식**입니다. 아래 순서대로 출력해서 1번 등기 봉투에 함께 넣으시면 됩니다.

## 2. 품목제조보고서 — 실무 체크포인트

### 2.1 어디서 뽑는가
식품안전나라(foodsafetykorea.go.kr) 로그인 → **품목제조보고** 메뉴 → 영업소 조회 →
해당 품목 선택 → **보고서(신고필증) 출력**.
※ 관할 시·군·구 축산물위생 담당 부서에서도 발급 가능합니다. 온라인 출력본이
거부되는 경우가 간혹 있으므로, **관인이 찍힌 발급본**을 함께 준비해 두시면 안전합니다.

### 2.2 백화점 QA가 실제로 대조하는 6가지
품목제조보고서와 **현재 판매 중인 라벨(포장 실물)** 이 아래 6개 항목에서 한 글자라도
다르면 보완 요청이 옵니다. 발송 전 반드시 대조하십시오.

| # | 대조 항목 | 흔한 불일치 사례 |
|---|---|---|
| 1 | **제품명(품목명)** | 라벨은 "A2 저지 헤이밀크", 보고서는 "저지우유" 등 구버전 |
| 2 | **식품유형** | 우유류 / 가공유류 / 발효유류 / 아이스크림류 — 유형이 바뀌면 표시기준도 바뀜 |
| 3 | **원재료명 및 함량** | 원유 100% 인지, 첨가물 유무 |
| 4 | **성상 / 포장재질** | 병(PET/유리) 변경 후 보고서 미변경 |
| 5 | **소비기한** | 라벨 "제조일로부터 O일" vs 보고서 값 불일치 (※ 유통기한 → **소비기한** 표기 전환 반영 여부) |
| 6 | **보존 및 유통방법** | "냉장 0~10℃" 문구 일치 |

> **핵심**: "현 버전"을 요구했다는 것은 **라벨 개정 이력이 있는지**를 보겠다는 뜻입니다.
> 라벨을 바꾼 적이 있다면 **변경보고 완료본**을 보내야 하며, 미변경 상태라면
> 발송 전에 변경보고를 먼저 처리하는 것이 순서입니다.

### 2.3 품목 단위로 각각 필요
품목제조보고는 **SKU가 아니라 품목(제품) 단위**입니다. 용량만 다른 경우
(예: 750mL / 500mL) 통상 1건으로 처리되나, **식품유형이 다르면 반드시 별건**입니다.

| 제품 | 예상 식품유형 | 보고서 별건 여부 |
|---|---|---|
| A2 저지 헤이밀크 | 우유류 | 별건 |
| A2 헤이밀크 | 우유류 | 별건 |
| 플레인 요거트 | 발효유류(농후발효유 등) | 별건 |
| 그릭요거트 | 발효유류 | 별건 |
| 카이막 | 유크림류 / 기타 【확인】 | 별건 |
| 아이스크림 | 아이스크림류 | 별건 |
| 밀크티 | 가공유류 / 음료류 【확인】 | 별건 |

→ **입점 1차 라인업으로 확정한 품목만** 보고서를 뽑아 보내고, 나머지는
"2차 확대 예정 품목"으로 소개서(3번)에만 언급하는 것이 심사 속도상 유리합니다.

## 3. 제조공정도 (동봉용 — 그대로 사용 가능)

**A2 저지 헤이밀크 제조공정** (송영신목장 자가 유가공)

```
① 원유 수유 (송영신목장 A2A2 저지 착유유 100%)
        ↓
② 냉각 저유 (0~4℃) · 수유검사 (관능/산도/알코올/항생물질)
        ↓
③ 여과 / 청정
        ↓
④ 균질 (APV 균질기)
        ↓
⑤ 살균 — 판형열교환기(Plate Heat Exchanger) / 75℃ · 20초
        ↓
⑥ 냉각 (10℃ 이하)
        ↓
⑦ 충전 (Filling)
        ↓
⑧ 포장 · 라벨링 · 코드 표시(제조일/소비기한/LOT)
        ↓
⑨ 자가품질검사 · 금속검출/외관 검사
        ↓
⑩ 냉장 보관 (0~10℃) → 냉장 출하
```

**중요관리 포인트**: ⑤ 살균 온도·시간 기록, ⑥ 냉각 종점온도, ⑩ 콜드체인 유지.
**공정 관리 기준**: 【확인】 HACCP 적용 여부 및 CCP 번호 기입.

## 4. 품질성적서(자가품질검사 성적서) — 실무 체크포인트

### 4.1 검사 주체
축산물 시험·검사기관 또는 KOLAS 공인시험기관 발행분을 권장합니다.
**자체 실험실 검사 결과만 제출하면 백화점 QA에서 반려되는 경우가 많습니다.**
→ 입점용으로는 **외부 공인기관 성적서 1부를 신규 의뢰**하시는 것을 권합니다.
(의뢰 → 결과 수령까지 통상 7~14일. **지금 바로 의뢰해야 등기 일정에 맞습니다.**)

### 4.2 제품유형별 필수 검사항목 (의뢰서에 이대로 기재)

**우유류 (A2 저지 헤이밀크 / A2 헤이밀크)**
- 성상, 산도, 유지방, 무지유고형분(SNF)
- 세균수, 대장균군
- 포스파타아제 (살균 적정성 확인)
- 항생물질(잔류물질) 불검출
- 【권장 추가】 이물, 방사능(요오드131·세슘134/137) — 프리미엄 채널 대응용

**발효유류 (요거트 / 그릭요거트)**
- 성상, 산도, 유산균수, 대장균군, 세균수(해당 시)

**아이스크림류**
- 세균수, 대장균군, 유지방, 유고형분

**카이막 / 밀크티** — 확정 식품유형에 따른 기준 적용 【확인】

### 4.3 성적서 발송 전 확인 3가지
1. **검체명이 라벨 제품명과 동일한가** (예: "우유"가 아니라 "A2 저지 헤이밀크")
2. **시험 결과가 전 항목 "적합"인가** — 한 항목이라도 부적합/재검이면 재시험 후 발송
3. **발행일이 3개월 이내인가**
