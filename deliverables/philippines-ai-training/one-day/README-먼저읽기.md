## 윤민중 교수와의 역할 분담 (겹침 제거 완료)

윤 교수 11개 강의(약 19.5시간)와 겹치지 않도록 다음을 **의도적으로 제외**했습니다.

| 제외한 내용 | 이유 |
|---|---|
| 난포파 이론 (recruitment·deviation·dominance) | 윤 교수 「Ovarian Follicular Dynamics」 3시간 |
| 발정주기 호르몬 생리 | 윤 교수 「Estrous Regulation」 |
| 초음파 원리·판독 | 윤 교수 「Ultrasonography」 **4시간**(실습·판독 워크숍 포함) |
| 물소 번식 | 윤 교수 5.5시간 |
| 키스펩틴 / 열스트레스와 난포 | 윤 교수 2시간 |
| 고능력우 번식성 결정요인 / 일반 호르몬 사용론 | 윤 교수 3시간 |

**회장님이 맡기로 하신 발정동기화**는 생리학이 아니라 **"수란우 동기화 = 달력"** 으로 구성했습니다.
윤 교수가 *왜 그런가*를 하고, 회장님이 *며칠에 무엇을 놓는가*를 합니다. 내용이 겹치지 않습니다.

**질병 파트(3.5시간)는 회장님만의 영역입니다.** 다른 강의에 전혀 없습니다.
