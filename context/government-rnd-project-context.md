- **연구노트 = 마스터 + 일지 방식.** 반복 작업(1일 2회 수작업 교반)은 마스터 연구노트 No.2(SOP-M1, 표준값·측정법)에 1회 상세 기록하고, 매일은 일일 교반 작업일지(변동값만), 매주 월요일 주간 측정표 + 주간 연구노트 요약(연구책임자 서명)으로 운영. 기존 reporting cadence(일일 점검표 → 주간 실증 일지)를 표준화한 것.
- **교반 주기:** 실증 기준선 기간(2026.11~1차 시제품 투입 전)은 **매일 아침·저녁 2회 고정** (기존 "아침 1회, 필요 시 2회"에서 변경). 목적 = 자율주행 교반기(갈전구리) 비교실증 기준선.
- **회의비 2,000천원 = 외부 전문가 자문회의.** 직원 내부회의가 아니라 산·학·관 외부 전문가 6인(1인 약 30만원) 초청, 2회(11월·12월 각 3인). 구성: 자문 수당 250천원×6 = 1,500 + 식비·다과 500. 참여기관(GMW·충남대·D2O) 소속은 외부 인원 아님. 공무원은 수당 지급 가능 여부 사전 확인(공무 참석 시 식비만).
- **직원 식비 집행처:** ① 외부 전문가 회의 동석분 → 회의비(식비) ② 참여연구원 야근·특근 식대(저녁 2회차 교반·기록) → 연구활동비 600천원(우편요금 1,000 → 400으로 조정, 연구활동비 총액 불변; KIAT·GMW 인정 여부 사전 확인) ③ 그 외 일상 식대·내부회의 식비·비참여 직원 식대 → ㈜디투오 자체 경비.
- 근거 규정: 국가연구개발사업 연구개발비 사용기준 — 회의비 식비는 외부 인원 참석 회의만 인정, 참여연구자만의 회의 식비 계상 불가. 2026년 개정(사전결재 폐지·외부참석자 범위 완화 보도)은 원문 미확인 → 사전결재는 계속 작성.
- 산출물: `deliverables/2026_산자부_마스터연구노트_No2_1일2회교반실증_D2O.{docx,pdf}`, `deliverables/2026_산자부_교반일지_데이터_D2O.xlsx`, `deliverables/2026_산자부_외부전문가자문회의_운영계획_D2O.{docx,pdf}`, 연구비 집행계획 엑셀 갱신.
