## [슬라이드 1] 한 장 요약

> **"대한민국 한우의 수도, 전남광주가 전국 최초의 '한우 AI 축산행정'을 시작합니다."**

- 전남은 **전국 최상위권 한우 사육 기반**(전국 2위권 ❏최신 통계 확정)을 보유한 대한민국 한우의 중심입니다.
- 그러나 한우 농가는 **발정을 놓쳐 송아지를 잃고, 분만사고로 소득을 잃고, 고령화로 사람을 잃고** 있습니다.
- **CowTalk AI + 반추위 센서**가 번식우 한 마리 한 마리의 발정·수정적기·분만·질병을 24시간 예측하고,
  그 데이터가 도정 대시보드로 연결되면 — 한우 행정이 **예측·예방·정밀 행정**으로 전환됩니다.
- 출발점: **한우 번식 ICT 시범사업 — 22개 시군 × 5농장 × 번식우 50두 = 5,500두 (설계안).**
- 선행 모델: 경기도 「AI 축산행정 플랫폼」 5개년 102.3억원 (정책연구 완료) — **전남광주는 한우 특화로 차별화.**

## [슬라이드 2] 왜 한우인가, 왜 지금인가

**한우 산업의 구조적 3대 손실 (농가 현장)**
1. **번식 손실** — 한우는 젖소보다 발정 발현이 약하고(미약·야간 발정) 관찰 인력은 부족
   → 발정 발견 실패 = 수정 기회 상실 = **1년에 송아지 한 마리를 못 받는 농가가 다수.**
2. **분만 손실** — 분만사고·송아지 폐사는 곧바로 수백만 원대 농가 손실 (송아지가 한우 농가의 월급).
3. **질병 손실** — 소모성 질병의 발견이 늦어 치료비 증가·성장 지연.

**행정의 구조적 한계**
- 이력제·가축시장·혈통 데이터는 쌓이는데 **행정과 실시간 연계가 없어** 사후 보고 중심.
- 시군별 번식 성적·질병 발생·수급 전망을 **실시간으로 보는 도구가 없음.**

**왜 지금인가**
- 「데이터기반행정 활성화에 관한 법률」 시행(2020.12) — 법적 기반 완비.
- 경기도가 낙농 중심 AI 축산행정을 시작 — **한우 특화 플랫폼은 아직 전국 어디에도 없음. 선점 기회.**
- 통합 전남광주특별시 출범 국면 — **통합 시대의 첫 농정 공동 어젠다**로 최적.

## [슬라이드 3] 무엇을 하는가 — 한우 특화 플랫폼 구조

**「전남광주 AI 축산행정 플랫폼 (한우 특화)」** = 번식우 체내 데이터 + 이력제·가축시장 데이터를 하나로 모아,
농가는 소득으로, 행정은 정책으로 쓰는 지역 인프라.

```
[입력]  반추위 센서(SmaXtec) — 반추·활동·체온·pH·음수 24시간
        + 이력제·가축시장(농협경제지주)·혈통(종축개량협회)·KOSIS·공공데이터
   ↓
[분석]  CowTalk AI (한우 모드) — 발정·미약발정 감지, 수정적기 알림, 임신 감시,
        분만 예측·난산 경보, 소모성 질병 조기경보, 사육 이상 탐지
   ↓
[행정]  Eco-BIT 대시보드 — 시군별 번식성적·질병지도·수급 전망 실시간 관제,
        저탄소 축산 데이터 관리, 근거 기반 축산정책·보고 자동화
```

**한우 농가에게 실제로 일어나는 일 (예시 시나리오):**
- 새벽 2시, 관찰이 불가능한 시간의 미약발정 → 센서가 감지 → 아침에 "오늘 오후 수정 적기" 알림.
- 분만 예정 번식우의 체온 변화 → "24시간 내 분만 임박" 경보 → 분만 사고·송아지 폐사 예방.
- 시군 담당자는 관내 번식성적·질병 징후를 대시보드로 실시간 확인 → 찾아가는 예방 행정.

## [슬라이드 4] 어떻게 증명하는가 — 한우 번식 ICT 시범사업 (설계안)

| 항목 | 내용 (설계안 — 정책연구로 확정) |
|---|---|
| 규모 | **22개 시군 × 5개 농장 × 번식우 50두 = 총 5,500두** (110농장) + 광주권 실증농가 별도 |
| 대상 | 번식우 중심 (한우 소득의 원천 = 송아지 생산) |
| 기간 | 3단계 36개월 — ①도입·기반(0~6M) ②AI·데이터 통합(7~24M) ③정책 실증·확산(25~36M) |
| 검증 | 선정·비선정 농가 비교 **무작위비교시험(RCT)** — 경기도 모델과 동일한 국제 표준 실증 설계 |
| 확산 | 번식 실증 → 비육·이력제 연계 → 낙농·양돈 확산 |

**측정 지표 (파일럿 목표치 — 실증으로 확정):**
발정 발견율 향상 · 수태율 개선 · 공태일수 단축 · 분만사고/송아지 폐사 감소 ·
소모성 질병 조기검출률 향상 · 행정 인지~대응 시간 단축 · 농가 노동시간 절감.

> 한우는 **수태율 개선이 곧 농가 월급**입니다. RCT로 "송아지가 몇 마리 더 태어났는가"를
> 숫자로 증명해 보고드립니다.

## [슬라이드 7] 왜 D2O인가 — 수행 역량

1. **센서 공급 채널** — SmaXtec 반추위 센서의 국내 공급·기술제휴 주체. 설치·등록·AS·데이터 연동 일괄
   (4년 유지·고장 시 무상 교체 조건). 경기도 정책연구(Antller Inc. 최종보고)에도 명시된 센서.
2. **한우 번식 전문성** — 제네틱스(수정란·번식)·고려동물병원(수의 임상) 기반의 번식 전문 조직.
   발정·수정적기·임신·분만의 전 주기를 아는 팀이 AI를 운영합니다.
3. **CowTalk AI 보유** — 센서 데이터 → 번식·질병·분만 예측 → 농가·수의사·행정별 맞춤 경보까지 완결형 분석 체계.
4. **선행 사업 정합** — 경기도 Phase 1 모델과 동일 아키텍처 → 시행착오 없이 한우 특화 적용.

→ **"센서(입력)+AI(분석)+번식 전문성(현장)을 한 주체가 책임"** — 한우 실증에 가장 빠른 길입니다.
→ 수행 구조: 전남광주(발주) — 주관기관 — D2O 컨소시엄(센서+AI+번식 실증 트랙 리드) — 지역 축협·생산자단체 협력.

## [부록] 예상 질의응답 (Q&A 대비)

**Q1. 경기도 사업과 무엇이 다른가?**
→ 경기도는 낙농(젖소) 중심 출발, 우리는 **한우 번식 중심** 출발입니다. 한우는 발정 발견과 송아지
생산이 농가 소득의 핵심이라 AI 효과가 가장 직접적으로 소득에 연결됩니다. 아키텍처는 검증된
경기도 모델을 준용하므로 시행착오 비용이 적습니다.

**Q2. 한우에도 반추위 센서가 효과 있는가?**
→ 반추위 볼러스 센서는 반추동물 공통 검증 기술로 유럽·북미에서 상용화되어 있습니다. 특히 한우처럼
발정 발현이 약한 품종일수록 체내 지표 기반 감지의 가치가 큽니다. 시범사업 RCT로 한우 실측 효과를
확정하는 것이 본 사업의 목적입니다.

**Q3. 농가 부담은?**
→ 시범사업 기간 농가 부담 최소화(도·국비 지원 설계). 농가에는 보고 의무가 아니라 **발정·분만·질병
알림이라는 혜택**이 먼저 갑니다. 고령 농가도 쓸 수 있게 간단 알림 중심으로 설계하고 교육을 병행합니다.

**Q4. 개인정보·농가 데이터 보안은?**
→ 농가-행정 데이터 경로를 분리하고 행정용은 집계·익명화합니다. 「데이터기반행정 활성화에 관한 법률」
체계 안에서 운영합니다.

**Q5. 예산 근거는?**
→ 경기도 선행 정책연구(5개년 102.3억원, 6대 과제 산정)가 준거입니다. 전남광주는 한우 특화 범위로
