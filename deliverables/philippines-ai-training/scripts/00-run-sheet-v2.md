## A. 이 과정의 성격

> **실습(hands-on) 없음. 전 과정 이론 강의입니다.**
> 생체 실습, 도축장 표본, 액체질소 탱크, 수조, 이식총 조작 실습 — **전부 없습니다.**
> 대신 **강의 + 판서 + 도해 + 사진 + 케이스 토론 + 사진퀴즈**로 구성했습니다.

실습이 없다는 것은 제약이 아니라 **설계 조건**입니다. 그래서 원고를 다음 원칙으로 썼습니다.

| 원칙 | 적용 |
|---|---|
| **기전(mechanism)으로 가르친다** | 손으로 못 익히니 머리로 남게. "왜 그런가"를 먼저 설명 |
| **숫자와 표로 남긴다** | 모든 프로토콜·수치를 표로 제시 → 포켓카드로 회수 |
| **판서를 많이 쓴다** | 각 원고에 `BOARD:` 지시. 난포파·간 대사·핑 위치 등은 반드시 그린다 |
| **청중을 계속 말하게 한다** | `ASK:` 지시. 거수·복창·케이스 토론으로 집중 유지 |
| **사진으로 임상안(眼)을 만든다** | M3 사진퀴즈 10장이 실습을 대신하는 유일한 시각 훈련 |

## D. 스크립트 사용법

각 스크립트 파일은 슬라이드 단위로 다음 형식입니다.

```
## S12 · [Slide title]
**SLIDE:** 화면에 띄울 내용 (표/그림/키워드)
**SAY:**   실제 발화 원고 — 그대로 읽으셔도 되는 문장
**ASK:**   청중에게 던질 질문
**BOARD:** 화이트보드에 쓸 것
**⏱:**     배정 시간
```

- **영문 파일(`-EN`)** = 강단 원고. 태블릿 또는 인쇄본 지참.
- **한글 파일(`-KR`)** = 동일 내용의 한국어 완전 대응본. 사전 학습용.
- 두 파일의 슬라이드 번호(S1, S2 …)는 **완전히 일치**합니다.

## E. 이론 강의 운영 시나리오

### E-1. 오프닝 10분 — 여기서 강의 성패가 갈립니다
1. **첫 3분:** 실적으로 신뢰 확보 — "18년, 연 3,000두 이식, 연 4,000개 공급, 평균 수태율 약 60% (Korea field data)."
2. **다음 4분:** 거수 질문 3개 —
   "AI 수태율 60% 이상인 분?" / "무발정 소로 고생하는 분?" / "수정란이식 해보신 분?"
   → 손 든 수를 **판서**해 두고, 종료 시 다시 언급.
3. **마지막 3분:** 오늘의 약속 — "실습은 없습니다. 대신 **프로토콜 표와 포켓카드**를 들고 나가십니다."

### E-2. 실습이 없을 때 집중력을 유지하는 5가지 장치
| 장치 | 언제 | 방법 |
|---|---|---|
| **판서** | 각 모듈 3~5회 | 난포파 곡선, 21일 타임라인, 간 대사 경쟁, 핑 위치, FTET 역산 |
| **복창** | 핵심 규칙 | "No CL, no transfer" / "Feed first, then synchronize" 는 소리 내어 함께 |
| **거수** | 파트 전환 시 | "본인 농장에서 이 문제 있는 분?" |
| **케이스 토론** | M2 부록 B | 4조 × 농장 케이스 1장, 조별 3분 발표 (시간 여유 시 또는 과제) |
| **사진퀴즈** | M3 S43 | 임상사진 10장 × 30초 — 실습을 대신하는 유일한 시각 훈련 |
