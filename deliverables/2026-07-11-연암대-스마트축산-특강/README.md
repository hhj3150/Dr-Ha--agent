# 연암대학교 축산 스마트팜 특강 (2026.07.11)

**주제:** 데이터로 소를 키운다 — 스마트 축산의 현재와 미래
**대상:** 연암대 축산 스마트팜 전공 학생 · **분량:** 약 45분 · **강사:** 하현제(수의사)

Eco-BIT / CowTalk AI / Genetics / D2O 생태계를 실제 사례로 활용한 교육용 특강입니다.
슬라이드 사진 15장은 **Higgsfield(힉스필드) AI**로 생성한 사실적 다큐멘터리 사진(2K, 16:9)입니다.

## 파일 구성

| 파일 | 용도 |
|---|---|
| **슬라이드.html** | 발표용 슬라이드 덱 24장 (브라우저에서 열어 방향키로 진행) |
| **강의대본.md** | 슬라이드별 발표 스크립트 + 타임라인 + Q&A 대비 + 강사 체크리스트 |
| **이미지-다운로드.sh** | 사진 15장을 `images/` 폴더로 내려받는 스크립트 |
| **이미지-URL-목록.md** | 사진 원본 URL·장면 설명 목록 |
| **images/** | 사진 저장 폴더(다운로드 스크립트 실행 후 채워짐) |

## 사용 방법 (3단계)

1. **사진 내려받기** — 인터넷이 되는 컴퓨터에서 이 폴더로 이동 후:
   ```bash
   bash 이미지-다운로드.sh
   ```
   (스크립트를 못 쓰는 환경이면 `이미지-URL-목록.md`의 URL을 브라우저로 하나씩 저장해
   `images/` 폴더에 해당 파일명으로 넣으면 됩니다.)

2. **슬라이드 열기** — `슬라이드.html`을 크롬 등으로 열고 **F키로 전체화면**.
   - `→` / `Space` : 다음, `←` : 이전, `F` : 전체화면, `Home`/`End` : 처음/끝
   - 화면 왼쪽 클릭 = 이전, 오른쪽 클릭 = 다음

3. **대본 준비** — `강의대본.md`를 인쇄하거나 노트북 옆 화면에 띄워 스크립트로 사용.

> 💡 인터넷만 연결돼 있으면 사진을 미리 안 받아도 슬라이드가 원격 URL에서 자동으로 사진을
> 불러옵니다. 다만 URL 만료·현장 네트워크 사정에 대비해 **강의 전 1단계 다운로드를 권장**합니다.
