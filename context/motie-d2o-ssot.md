# 산자부 과제 RS-2026-25508014 — ㈜디투오 단일 기준(SSOT) · 연구관리 기준서

**최상위 기준 문서.** 산자부 과제 관련 모든 답변·문서는 이 파일을 먼저 읽고, 아래 "고정 사실"과 충돌하는 내용을 만들지 않는다.
하실장은 이 과제의 **연구관리 책임자(30년 경력 관점)** 로서 ① 데이터 일관성 ② 디투오 역할 준수 ③ 최종평가·정산 결격 사유 예방을 책임진다.
회장님이 새로 주는 자료·사실은 즉시 이 파일(및 관련 context)에 추가하고 이후 계속 유지한다. 이전 사실을 바꿀 때는 지우지 않고 "~에서 ~로 변경(일자)"로 남긴다.

## 1. 과제 기본
- 사업: 10대 메가프로젝트 기술산업화 · 과제번호 RS-2026-25508014

- 기간: 2026. 4. 1. ~ 2028. 12. 31. (33개월) · 주관 ㈜GMW(공철주) · 공동 충남대 산학협력단(김용주) · 공동(수요사) ㈜디투오
- 전문기관: KIAT (과제담당 김현지) · 현장점검 2026. 10. 30. (실증지)

## 2. 디투오 역할 (계획서 기준, 절대 기준)
- **실증 지원 = 갈전구리 실증 테스트 + 영업·판매(홍보·교육 포함)**: 실증 환경 구축·현장 실증 지원 / 사업화 제품 영업·기술 교육·컨설팅 등 확산 기반 구축
- ① 실증지 HBP 침상 일상 관리(1일 2회 수동 교반 기준선) ② 시제품 나오면 현장 실증 ③ 영업·판매
- **하지 않는 것:** 기계·장비·센서·자율주행 기술 개발·사양 결정(충남대·GMW 소관). 요구사항은 수요자 관점(R1~R13)으로만.
- 연차: 1차년도 실사용 환경 정의·실증 준비(요구사항 정의서, 기준 데이터) / 2차년도 1차 시제품 실증(현장 실증 보고서) / 3차년도 2차 시제품 최종 실증·레퍼런스·영업·판매
