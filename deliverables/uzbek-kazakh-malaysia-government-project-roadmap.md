## 0. 전제 (회장님 정책)
- **Vehicle:** 올해 진행 중인 **KOPIA(코피아) 사업** = 농촌진흥청(RDA) 해외농업기술개발사업 (예산·기간·우리 역할 = TBD, 회장님 확인).
- **대상국:** 우즈베키스탄 · 카자흐스탄 · 말레이시아.
- **사업축:** ① **한국 홀스타인 성감별(암) 수정란 수출** + ② **CowTalk(반추위 센서 기반 AI 축산 플랫폼)** — 두 축을 **하나의 통합 패키지**로.
- **인프로와의 관계:** 인프로는 **KOICA(외교부 무상원조)** 사업, 우리는 **KOPIA(RDA 농업기술개발)** 사업 — **재원·기관·성격이 다른 별개 사업.** 직접 경쟁 아님. 인프로 센서공급 요청 거절이 우리 사업에 지장 없음.
- **강점:** KOPIA는 현지 센터·정부 농업기술 네트워크를 보유 → 신뢰·현지 인프라에서 단발 KOICA 파일럿(인프로) 대비 우위. 유전개량+정밀축산은 KOPIA 취지(농업기술 이전)에 정확히 부합.
- **기밀규칙:** 수출 대상은 **홀스타인 성감별 유제품용 수정란만**. **한우 유전자원 수출은 절대 불가.**

## 1. 통합 패키지의 핵심 논리 — 왜 "수정란 + CowTalk"인가

두 축을 붙이면 경쟁자(인프로 포함)가 복제 불가능한 구조가 됩니다.

```
수정란 수출 → 현지 수란우 이식 → 임신·분만 → 개체 탄생
                    │
              CowTalk 센서 장착
                    │
   발정·임신·분만·질병 예측 + 데이터 축적
                    │
   유전개량 성과 추적 + 정부 데이터 허브 + 금융/보험 연계
```

- **수정란**만 팔면 1회성. **CowTalk**만 팔면 하드웨어. **둘을 붙이면** "유전개량 + 상시 데이터 관리"의 경상수익·국가 데이터 자산이 된다.
- 이것이 우리가 §competitive-analysis에서 정의한 **"상위 레이어"** — 인프로가 못 하는 영역.

## 3. 국가별 실행 개요

### 3-A. 우즈베키스탄 (1순위 — 통합 레퍼런스 완성 / 사이트: 술탄목장 + 신규 1)
- **사이트:** ① **술탄목장** — 기존 설치 확장(추가 볼러스 + 데이터 연동), ② **신규 목장 1곳** — 풀패키지 설치. 술탄목장을 통합 데모의 앵커로.
- **수정란:** 기존 RDA/농진원 협력 성과를 정량화(수출두수·수태율·생산개체). 올해 프로젝트 물량·일정 확정.
- **CowTalk:** 술탄목장 기존 실증 결과 정량화(발정검출율·분만/질병 조기경보 정확도) → 수정란 생산 개체에 센서 장착해 **"수정란→CowTalk 추적" 통합 데모** 구성.
- **정부:** 농업부·수의당국과 데이터 연계 협의(방역·개체이력). 금융/보험 연계 가능성 스캔(가축대출 리스크 데이터).
- **1순위 산출물:** 통합 패키지 1-pager + 우즈벡 정부/파트너용 제안서.

### 3-B. 카자흐스탄 (2순위 — 중앙아 복제 / 사이트: 목장 2곳)
- **사이트:** 신규 목장 2곳 — 우즈벡 검증 모델을 그대로 이식하는 중앙아 첫 착지.
- 수입 검역·Export Permit·Health Certificate 요건 국가별 확인. 현지 파트너/유통 채널 발굴. G2G·KOICA/ODA 연계 옵션 검토.

### 3-C. 말레이시아 (2순위 — 동남아 교두보, 별도 현지화 / 사이트: 미정)
- **사이트 미정** — 동남아·할랄 특성상 현지화·규제 선행 후 사이트 선정.
- 열대·할랄 환경 특성 반영(수란우 관리·냉방·사료 조건). 동남아 낙농 정책·수입규제 확인. CowTalk 현지어/현지 UX 및 데이터주권 요건 점검.

## 7. 즉시 필요한 입력 (회장님 확인 사항)
1. **KOPIA 사업 실체:** 사업 정식 명칭 / 예산 / 기간 / 우리 역할(주관·참여) / 국가별 KOPIA 센터 연계 여부(우즈벡·카자흐 有, **말레이시아 KOPIA 센터 유무 확인** — 미정 사유일 수 있음).
2. **사이트별 두수** — 술탄목장(추가분)·우즈벡 신규 1·카자흐 2곳 각 규모(센서 물량·수정란 두수 산정 근거). *사이트 구성은 확정: 우즈벡 2 + 카자흐 2, 말레이시아 미정.*

4. 금융/보험 연계를 사업축으로 세울지(우즈벡 우선).
