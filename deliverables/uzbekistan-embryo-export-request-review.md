# 우즈베키스탄 수정란 수출의뢰 공문 — 검토 및 수정사항

- **검토 대상:** `수출의뢰_우즈베키스탄_수정란수출20250922.hwpx` (Google Drive, 시행 2025. 9. 20)
- **비교 자료:** `수출의뢰_우즈베키스탄_수정란수출20240822.pdf` (시행 2024. 8. 22)
- **수신:** NH농협무역 대표이사 / **발신:** ㈜제네틱스
- **담당 에이전트:** Global Embryo Export Operations (수출·검역·물류) + Genetics Lab Operations (수정란 사양)
- **검토일:** 2026-10-07
- **상태:** 검토안(Draft). 수량·금액·일정·서류번호는 회장님 확인 후 확정.

> 2025년 공문은 2024년 공문에서 **수량(20 → 30EA)과 시행일만 바꾼 형태**입니다.
> 2024년 문서의 오류가 그대로 넘어왔고, 수량을 바꾸면서 금액과 맞지 않는 문제도 새로 생겼습니다.

## 3. 발송 전 확인 사항 (회장님 결정 필요)

| 항목 | 확인할 내용 |
|---|---|
| 금액 | 30EA 기준 900만원인지, 600만원(단가 인하)인지. USD 환산액과 가격조건 |
| 운송 용기 | Dry shipper 사용 여부. 용기를 회수할지(반송) 수입자에게 넘길지 |
| 수입허가서 | 이번 선적에 유효한 허가서인지(발급일·유효기간). 수량 30EA가 허가 범위 안인지 |
| 사업명 | 농진청 지침서가 해당 연도 사업(예: KOPIA 우즈베키스탄 센터 연계)과 맞는지 |
| 수입자 | Consignee 정보(Sultan Farm 등) — 수입허가서상 명의와 같아야 함 |
| 검역 | 수입국 위생조건에 맞춘 공여우 검사 성적, IETS 기준 세척·처리 기록 준비(Genetics Lab Operations) |

## 4. 다음 단계

1. 회장님이 §3 항목을 확인하시면 수정 공문 최종본을 작성합니다(HWPX 원본 수정 가능).
2. Genetics Lab Operations: 수출용 30개의 스트로 번호, 공여우·종모우 정보, 동결일 목록을 정리합니다.
3. Global Embryo Export Operations: 수입국 위생조건과 검역본부 수출검역 신청 서류를 대조해 체크리스트를 만듭니다.
4. NH농협무역과 Dry shipper의 항공사 접수 가능 여부, 비위험물 처리를 사전에 협의합니다.

> 비고: 위험물 분류(IATA A152), 가격조건, 허가 유효기간은 일반 기준에 따른 검토 의견입니다. 최종 판단은 NH농협무역(통관·항공)과 농림축산검역본부에서 확인해야 합니다.
