## D. 스크립트 사용법 (강사용)

각 스크립트 파일은 슬라이드 단위로 다음 형식입니다.

```
## S12 · [Slide title]
**SLIDE:** 화면에 띄울 내용 (표/그림/키워드)
**SAY:** 실제 발화 원고 — 그대로 읽으셔도 되는 문장
**ASK:** 청중에게 던질 질문
**BOARD:** 화이트보드에 쓸 것
**⏱:** 배정 시간
```

- **영문 파일(`-EN`)** = 강단 원고. 태블릿/인쇄본으로 지참.
- **한글 파일(`-KR`)** = 동일 내용의 한국어 완전 대응본. 사전 학습·내용 확인용.
- 두 파일의 슬라이드 번호(S1, S2 …)는 **완전히 일치**합니다.
