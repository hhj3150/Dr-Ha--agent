## 4. 강사용 발음·표현 주의

| 표현 | 권장 |
|---|---|
| 숫자 | 화면을 짚으며 **두 번** 말한다 ("day seven — day seven") |
| 단위 | metric only (mm, mL, kg, °C, L). 미국식 단위 사용 금지 |
| 약어 | 첫 등장 시 **풀네임 + 약어** ("Fixed-Time AI, F-T-A-I") |
| 질문 | "Any questions?" 대신 **"Who has a cow like this now?"** |
| 문장 | 1문장 1메시지. 관계대명사 중첩 금지 |
