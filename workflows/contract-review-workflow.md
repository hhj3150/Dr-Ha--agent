# Contract Review Workflow (계약서 검토 워크플로)

## Step 1 — 계약 성격 규정
매매 / 공급 / 대리점·총판 / 구독(계속거래) / 용역·도급 / 공동연구 / 라이선스 / 투자 /
근로 / NDA / MOU(구속력 유무 반드시 확인).
→ 성격에 따라 강행법규가 달라진다. 대리점=대리점법, 하도급=하도급법, 소비자=전자상거래법.

## Step 2 — 13대 필수 조항 점검표
| # | 조항 | 점검 포인트 |
|---|---|---|
| 1 | 당사자 | 법인명·사업자번호 정확, 대표권 있는 자의 서명인가 |
| 2 | 계약목적·범위 | 무엇을 어디까지. 범위 모호 = 분쟁의 90% |
| 3 | 대금·지급조건 | 금액·부가세 별도 여부·지급시기·지연이자 |
| 4 | 기간·갱신 | 자동갱신 조항의 유불리, 갱신 거절 통지기한 |
| 5 | 해지 | 즉시해지 사유, 통지기간, 해지 시 정산 |
| 6 | 손해배상 | **한도(cap) 반드시 설정**, 간접·특별손해 배제 |
| 7 | 지체상금 | 요율·상한 |
| 8 | IP 귀속 | 개발결과물·개량발명·데이터의 귀속과 실시권 |
| 9 | 비밀유지 | 범위·기간·반환·잔존의무 |
| 10 | 경업·전속 | 과도한 제한은 무효 가능 |
| 11 | 개인정보 | 처리위탁 여부, 위탁계약 별도 필요성 |
| 12 | 준거법·분쟁해결 | 국내=관할법원 / 국제=중재기관+준거법 명시 |
| 13 | 불가항력 | 가축전염병·방역조치 포함 여부(축산업 필수) |

## Step 3 — 사업별 추가 점검
- **센서 구독 계약**: 고장·오작동 시 책임, AS 기한, 데이터 소유권, 해지 시 기기 회수,
  **AI 예측 오류에 대한 책임 한정 문구**(수의사 진료 대체 아님)
- **대리점 계약**: 구입강제·판매목표 강제·일방적 해지 → 대리점법 위반 소지
- **수출 계약**: 인코텀즈, 검역 불합격 시 위험부담, 대금회수(L/C), CISG 적용 배제 여부
- **공동연구·정부과제**: 협약서상 IP 귀속이 우선. 협약과 충돌하는 조항 금지
- **근로계약**: 임금 구성, 근로시간, 수습, 외국인 표준근로계약서 사용 여부

## Step 4 — 조항별 검토표 작성
| 조항 | 현재 문언 | 리스크 | 수정안 | 협상 우선순위(A/B/C) |
|---|---|---|---|---|
A = 이것 없으면 서명 불가 / B = 강하게 요구 / C = 양보 가능

## Step 5 — 결론 + 에스컬레이션
고액·장기·해외 계약의 **최종본은 변호사 검토 후 서명**을 권고한다.
표준 고지문 부착.
