## B. 블록별 학습목표 (Learning Objectives)

교육 종료 시 참가자는 다음을 **혼자서 할 수 있어야** 합니다.

**M1 수정란이식**
1. IETS 기준으로 수정란 발육단계·등급을 읽고 이식 가능 여부를 판단한다.
2. 수란우 선발 7개 기준을 적용해 합격/불합격을 판정한다.
3. 직접이식(DT) 동결수정란을 규정대로 해동·장전한다.
4. 황체 쪽 자궁각 선단 1/3에 이식하는 순서를 말할 수 있다.
5. 임신율이 떨어지는 상위 5개 원인을 지목하고 교정한다.

**M2 발정동기화**
6. 발정주기 21일 안에서 PGF2α와 GnRH가 언제 듣고 언제 안 듣는지 설명한다.
7. 농장 상황(경산우/미경산우/무발정/수란우)에 맞는 프로토콜을 선택한다.
8. Ovsynch / 5-day CO-Synch+CIDR / FTET 프로토콜을 날짜·시간표로 작성한다.
9. 호르몬 보관·투여·기록의 현장 규칙을 지킨다.

**M3 다발성 질병**
10. 이행기 4대 질병(유열·케톤증·후산정체·자궁염)의 현장 징후를 구분한다.
11. 번식장애(난소낭종·무발정·반복수정)를 수정 실패 원인과 연결한다.
12. 열스트레스가 수태율을 떨어뜨리는 기전과 대응을 설명한다.
13. 수정사 본인이 **농장 간 질병 전파 매개**가 되지 않도록 방역수칙을 실행한다.

## C. 운영 시나리오 (강사·운영진용)

### C-1. 오프닝 15분 — 여기서 강의 성패가 갈립니다
1. **첫 3분:** 강사 실적으로 신뢰 확보 —
   "18년, 연 3,000두 이식, 연 4,000개 수정란 공급, 평균 수태율 약 60% (Korea field data)."
2. **다음 5분:** 청중에게 질문 3개 (거수) —
   - "AI 수태율 60% 이상인 분?" / "무발정 소 때문에 고생하는 분?" / "수정란이식 해본 분?"
   → 손 든 수를 화이트보드에 적고, 종료 시 다시 물어 변화를 보여줌.
3. **마지막 7분:** 오늘의 약속 — "오늘 끝나면 여러분은 **프로토콜 표 3장과 포켓카드**를 들고 나갑니다."

### C-2. 실습 데모 (M1-B, 25분 배정)
- 스테이션 4개 × 5명 순환 (각 6분)
  - ST1 해동: 37°C 수조, 스트로 판독, 타이머
  - ST2 장전: ET gun + sanitary sheath 조립, 더미(모형) 삽입
  - ST3 촉진/초음파: 도축장 생식기 표본 또는 모형으로 황체 확인
  - ST4 기록: 이식기록지 작성 실습
- **비상 대안:** 생체 실습 불가 시 → 영상 + 모형 + 스트로 실물(공(空)스트로)로 대체.

### C-3. 케이스 워크숍 (M2-B, 25분)
- 4조 × 5명. 각 조에 농장 케이스 카드 1장 배부(`02` 부록).
- 과제: "이 농장의 다음 30일 동기화 캘린더를 날짜/시간으로 작성하라."
- 조별 3분 발표 → 강사 즉시 교정. **이 시간이 참가자 만족도를 만듭니다.**

### C-4. 클로징에서 반드시 할 것
- [ ] 사후 Q&A 채널(Viber/WhatsApp 그룹) 개설 및 QR 안내
- [ ] 시범 이식 참여 희망 농장 신청서 수거 (목표 3~5곳)

## D. 통역·언어 운영

| 항목 | 방침 |
|---|---|
| 슬라이드 | **영문 100%** (전문용어 병기) |
| 구두 강의 | 영어. 문장 짧게, 1문장 1메시지 |
| 통역 | 순차통역 1명 상시 대기. 프로토콜·용량 설명 시 **반드시 통역** |
| 용어 | 첫 등장 시 영문 풀네임 + 약어 (예: Fixed-Time AI = FTAI) |
| 배포물 | 영문. 포켓카드는 그림·표 중심 |
| 금지 | 한국어 단독 슬라이드, 한자, 긴 문어체 |

**강사 영어 전달 팁 3가지**
1. 숫자는 화면을 짚으면서 두 번 말한다 ("day seven — day seven").
2. 프로토콜은 반드시 **날짜 표**로 보여주고 말로 설명한다.
3. 질문은 "Any questions?"(반응 없음) 대신 **"Who has a cow like this now?"** 로 던진다.
