# 슬라이드 사용법 — 발표자 노트로 강의하기

회장님, **원고를 따로 들고 다니실 필요가 없습니다.**
각 슬라이드의 **발표자 노트에 영어 대사 전문**이 들어 있습니다.
발표자 보기(Presenter View)를 켜면 **회장님 노트북 화면에만** 대사가 보이고,
**빔프로젝터에는 슬라이드만** 나갑니다.

---

## 1. 파일 3개

| 파일 | 모듈 | 슬라이드 |
|---|---|---|
| `Module-1-Embryo-Transfer.pptx` | 수정란이식 (120분) | 46장 |
| `Module-2-Estrus-Synchronization.pptx` | 발정동기화 (120분) | 47장 |
| `Module-3-Rumen-Physiology-and-Diseases.pptx` | 반추위 생리·질병 (120분) | 53장 |

합계 **146장**. 표지·파트 구분·마무리 슬라이드가 포함된 수치입니다.

---

## 2. 발표자 보기 켜는 법 (가장 중요)

### 노트북 + 빔프로젝터 연결 후

**Windows**
1. 프로젝터 연결 → `Windows 키 + P` → **"확장"** 선택 (⚠️ "복제" 아니고 **확장**)
2. PowerPoint에서 **슬라이드 쇼** 탭 → **"발표자 보기 사용"** 체크
3. `F5` 로 시작

**Mac**
1. 시스템 설정 → 디스플레이 → **"디스플레이 미러링" 해제**
2. PowerPoint → **슬라이드 쇼** → **"발표자 보기"** 체크
3. 슬라이드 쇼 시작

### 발표자 보기 화면 구성
```
┌───────────────────────────┬──────────────────┐
│                           │  다음 슬라이드    │
│      현재 슬라이드         ├──────────────────┤
│                           │  ★ 영어 대사      │
│                           │    (여기를 읽으심) │
└───────────────────────────┴──────────────────┘
```
노트 글씨가 작으면 노트 창 아래 **A^ 버튼**으로 키우십시오.

### 화면이 바뀌어 나올 때
프로젝터에 발표자 보기가 나가고 노트북에 슬라이드가 나오면,
발표자 보기 왼쪽 위 **"디스플레이 설정" → "발표자 보기와 슬라이드 쇼 바꾸기"** 를 누르십시오.

## 3. 노트 안에 들어 있는 것

```
"Good morning, everyone. My name is Dr. Hyunje Ha…"   ← 그대로 읽으시면 되는 영어 대사

[ASK] Who here achieves more than sixty percent…       ← 청중에게 던질 질문
[BOARD] Circle the denominator L and write…            ← 화이트보드에 그릴 것
[TIME] 5'                                              ← 이 슬라이드 배정 시간
```

- **[BOARD]** 는 꼭 그려 주십시오. 실습이 없으므로 판서가 유일한 시각적 무기입니다.
- **[TIME]** 을 합산하면 각 모듈 120분이 됩니다. 뒤처지면 표 슬라이드에서 속도를 내십시오.

---

## 4. 슬라이드에서 알아두실 표시

| 표시 | 뜻 |
|---|---|
| 우측 상단 **KEY SLIDE** (주황) | 이 모듈에서 가장 중요한 슬라이드 — 시간을 더 쓰십시오 |
| 하단 좌측 | 모듈명 |
| 하단 우측 `S24 \| 27` | 원고 슬라이드 번호 `S24` / 덱 내 순번 `27` |
| 제목 뒤 **(cont.)** | 내용이 길어 다음 장으로 이어진 슬라이드 |
| **진한 초록 전면 슬라이드** | 파트 구분 — 여기서 한 번 쉬어 가며 전환하십시오 |

`S24` 번호는 원고 파일(`scripts/M2-…-EN.md`, `-KR.md`)의 슬라이드 번호와 **정확히 일치**합니다.
한글 원고에서 내용을 확인하시고 같은 번호를 슬라이드에서 찾으시면 됩니다.

---

## 5. 인쇄 (권장)

프로젝터 고장에 대비해 **노트 포함 인쇄본**을 1부 지참하십시오.

`파일 → 인쇄 → 설정 → "전체 페이지 슬라이드" 클릭 → "슬라이드 노트" 선택`

교육생 배포용은 `유인물 → 3슬라이드` 로 하시면 우측에 필기 줄이 생깁니다.

---

## 6. 강의 전 점검 3가지

- [ ] 강의장 노트북이 아닌 **회장님 노트북**을 쓰십시오 (노트가 그 안에 있습니다)
- [ ] USB에 3개 파일 백업 + 클라우드 1부
- [ ] 화면비 확인 — 이 덱은 **16:9 와이드**입니다. 4:3 프로젝터면 위아래 여백이 생기지만 내용은 잘리지 않습니다

---

## 7. 수정이 필요하시면

슬라이드는 원고(`scripts/*-EN.md`)에서 **자동 생성**한 것입니다.
내용을 크게 바꾸실 때는 원고를 고친 뒤 다시 생성하는 편이 정확합니다.
문구 몇 개만 바꾸실 때는 PowerPoint에서 직접 수정하셔도 됩니다.
