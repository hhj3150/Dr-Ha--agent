## 로봇소똥구리 — 산자부 과제 (슬라이드 20~21)

과제명 «축사 환경 개선을 위한 자율주행 깔개 관리 축산 로봇 개발 및 사업화»
(RS-2026-25508014, 10대 메가프로젝트 기술산업화).
2026.4~2028.12 (33개월) · 총 연구개발비 49.7억원(정부지원 37억원) · TRL 5→9 ·
㈜GMW(주관) + 충남대학교 산학협력단(공동·기술) + ㈜D2O(공동·수요·실증).

HBP 운영 SOP 슬라이드에서 "교반이 성패를 가른다"고 짚은 뒤,
그 교반 노동을 자동화하는 과제로 잇는 배치입니다.

이어지는 **슬라이드 22는 이번 세미나의 핵심 요청**입니다 — R&D가 끝난 뒤 보급하는
순차 방식 대신, 과제 3년(2026~2028) 동안 보급사업을 병행하자는 제안. 국가 R&D 트랙과
기술보급 트랙을 연차별로 나란히 놓고, 양측이 각각 얻는 것을 명시했습니다.

**대외 발표에서 제외한 항목** — 시제품 재료비 내역, 예상 판매가, 로열티율.
사업화 수치는 주관기관(GMW)·충남대 소관이므로 이 덱에 넣지 않았습니다.

## 시범사업 제안 (슬라이드 44~48)

기본 5건 — A 저지·A2A2 축군 조성 / B 피트모스 HBP 악취저감 정량 / C 정밀낙농 센서 /
D 소규모 유가공 표준모델 / E 순환농업 퇴비 품질

G **생산–소비 디지털트윈**(목장은 스마트팜, 공장은 스마트팩토리 미구축 → 데이터가 착유탱크에서 단절.
스마트팩토리 구축 → 농장-공장 데이터 연결 → 제품 QR로 소비자 이력 개방)

## 표현·claim 원칙

세미나 청중이 국가 연구기관 인력이므로 근거 구분을 명시했습니다.

- 저지/홀스타인 체중·유성분·산유량 → **문헌 참고 범위**로 표기, 목장 실측치와 구분
- 부가가치 그래프 → **개념도**임을 명시 (회계 수치 아님)
- HBP 효과 → '현장 체감'과 '실증으로 검증할 것'을 좌우로 분리
- A2 → 유전형 사실만 표시, 건강 효능 주장 없음
- Hay Milk → 국내 법정 인증 기준 부재를 명시하고 사양 방식만 사실로 설명
- 인허가 → 관할 기관 사전 협의 필요를 명기
- 센서 가격 → 대외 공개 가능 범위(설치비, 두당 월 구독료, 유지 기간)만 기재
