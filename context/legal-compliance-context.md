# Legal & Regulatory Context (대한민국 법령 맵)

This file is the legal-risk map for Dr. Ha Hyunjae's ecosystem. The Legal &
Regulatory Compliance Agent reads it before every review. It maps **which Korean
statutes touch which business**, so no deliverable leaves the system without the
relevant law being checked.

> **Status of this file:** a routing map, **not** a substitute for the statute text.
> Korean law changes constantly (시행령/시행규칙/고시/조례 especially). Every article
> number cited in an output must be verified against the primary source before it is
> relied on. See "Verification discipline" below.

---

## 0. Verification discipline (절대 규칙)

1. **Primary sources only.** 국가법령정보센터(law.go.kr) for 법률·시행령·시행규칙·행정규칙,
   자치법규정보시스템(elis.go.kr) for 조례·규칙, 대법원 종합법률정보 for 판례,
   각 부처 고시/지침 for 실무 기준.
2. **Never state an article number from memory as fact.** Any 조문 that has not been
   checked against the primary source in this session is marked
   `[조문 확인 필요]`. A confident-sounding wrong 조문 is worse than an honest gap.
3. **Three-tier confidence labels** on every legal statement:
   - `확인됨` — verified against primary source this session (cite source + date)
   - `일반원칙` — settled general principle, low risk, article not verified
   - `확인 필요` — needs statute check or professional confirmation
4. **AI is not a licensed professional.** This agent produces *internal risk screening*.
   It never issues a legal opinion (법률의견서) in the sense of 변호사법. Matters on the
   **Escalation list** (§9) go to a licensed 변호사 / 변리사 / 노무사 / 세무사 / 관세사.
5. **변호사법 주의.** Do not draft documents for third parties as if practicing law, and
   do not present output as an attorney opinion. Internal-use framing only.
6. **Foreign law is out of scope for opinion.** UAE, Uzbekistan, Kazakhstan, Malaysia,
   Indonesia, Thailand, Vietnam, Philippines law → identify the issue, then require
   **local counsel**. Never assert foreign statutes as settled.
7. **Effective dates matter.** Always state 시행일 and whether 경과규정/부칙 applies.

외국인근로자의 고용 등에 관한 법률(E-9 농축산업) / 남녀고용평등법 / 파견법 / 4대보험 관계법

- **목장·실험실은 중대재해 리스크 실물 구간.** 안전보건 체계 구축 여부가 대표이사
  형사책임과 직결.
- 농축산업 근로시간·휴게 특례 적용 여부는 사업장 실태에 따라 달라짐 → `확인 필요`.
- 외국인 근로자 사업장 변경·숙소 기준·표준근로계약서 위반은 고용허가 취소로 직결.

### 8-4. 회사·자본
상법 / 벤처기업육성에 관한 특별법 / 중소기업기본법 / 자본시장법(투자유치 시) /
외국환거래법(**두바이 법인 설립 = 해외직접투자 신고 대상**) / 법인세법·부가가치세법

- 다수 법인(Genetics, D2O, 동물병원) 간 거래는 **특수관계자 거래**로 세무 리스크. 정상가격
  근거 문서화 필요.
- 투자유치 IR 자료의 수치는 이후 진술보장(R&W) 책임으로 연결됨.

## 9. Escalation list — 반드시 유자격 전문가에게 넘길 사안

이 목록에 해당하면 에이전트는 **자체 결론을 내지 않고** 전문가 연결을 권고한다.

1. 소송·수사·행정처분·과징금이 이미 개시된 사안 → **변호사**
2. 형사 리스크 (연구비 부정, 청탁금지법, 중대재해, 식품 위해) → **변호사**
3. 특허 출원·심판·침해 판단, 상표 등록 가능성 최종 판단 → **변리사**
4. 해고·징계·산재·노동위원회 사건 → **노무사 / 변호사**
5. 세무조사, 특수관계자 거래 가격, 이전가격 → **세무사 / 회계사**
6. 수출 통관·품목분류·관세 최종 확정 → **관세사**
7. 외국법이 준거법인 계약, 해외법인 설립·지분 구조 → **현지 로펌**
8. 실제 체결 직전의 고액·장기 계약 최종본 → **변호사 검토 후 서명**
